# VFC (Volume Fork Class) 🚀

> *"Это мясо даже веган схавает."*

**VFC** — это уникальный, мощный и интуитивный скриптовый движок для автоматизации, управления файловой структурой и проверки окружения. Создан для тех, кому надоел скучный синтаксис классических языков программирования.

---

## ⚙️ Основные возможности

* **Файловая магия (`p::apka:`):** Создание папок, генерация файлов и запись контента на лету.
* **Умные переменные (`va::rik:`):** Объявление переменных и их удобная подстановка через `${var}`.
* **Интерактив (`v::opros:`):** Опрос пользователя с сохранением введенных данных.
* **Циклы (`z::ikl:`):** Повторение блоков команд нужное количество веток.
* **Проверки (`k::a::k:`):** Анализ файлов (существование, количество строк, размер в МБ/ГБ).
* **Контроль отладки (`o::tlad::ka`):** Полное отключение системной «шелухи» и логов в один клик.
* **Модульность (`import::use`):** Подключение встроенных математических и рандомных библиотек, а также модулей Python.

---

## 🛠️ Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/mako986/VFC.git
   ```
2. Создайте файл с вашим кодом и расширением `.vfc` (например, `main.vfc`).
3. Запустите интерпретатор через терминал:
   ```bash
   python vfc.py main.vfc
   ```

## 📜 Пример скрипта (`main.vfc`)

```text

[version = 2.1]
vce

z::ikl: 2

[Инициализация...]

vce

p::apka:
[folder]
--{davai}
---[config.json, info.txt]

-=[info.txt]

vce

vce::ne

```
