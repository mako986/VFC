VFC (Volume Fork Class)

Официальный справочник команд и руководство по использованию языка v2.1

1. Как установить и запустить проект

  1. Клонируйте репозиторий проекта: git clone https://github.com/mako986/VFC.git
  2. Создайте файл с исходным кодом и расширением .vfc (например, main.vfc).
  3. Запустите код через терминал ОС Windows командой:
python vfc.py main.vfc

2. Подробный справочник команд VFC

vot::tut::vivod:

Команда, делающая вывод текста в консоль (поддерживает вывод переменных через ${var_name}). Завершается ключевым словом vce.

Пример использования:

vot::tut::vivod:
[Привет, мир! Это консоль VFC.]
vce

o::tlad::ka

Команда для отключения или включения отладки. Позволяет убрать всю лишнюю «шелуху» (системные сообщения вроде [VFC System] и пути созданных папок) из консоли.

Пример использования:

o::tlad::ka otkl   <-- отключить отладку
o::tlad::ka vkly   <-- включить обратно

va::rik:

Команда для объявления пользовательских переменных. Позволяет задавать значения и использовать их в тексте или путях файлов.

Пример использования:

va::rik:
[a = 10]
[author = mako]
vce

v::opros:

Команда интерактивного опроса пользователя. Выводит вопрос в консоль, ожидает ввод с клавиатуры и сохраняет результат.

Пример использования:

v::opros:
[Введите имя себя: ]
vce

z::ikl:

Команда цикла. Позволяет выполнять внутренний блок команд заданное количество раз.

Пример использования:

z::ikl: 5
vot::tut::vivod:
[Повтор цикла...]
vce
vce

k::a::k:

Умный блок логической проверки. Проверяет существование файлов, количество строк или размер.

Проверка строк (например):

k::a::k:
[primer.json]
--{stroki}
---[апвзап]
vce

Проверка размера (например):

k::a::k:
[primer2.json]
--{razmer}
---[12.2 MB]
vce

Проверка существования (например):

k::a::k:
[primer3nax.json]
--{m}
---[json in.json]
vce

p::apka:

Команда для создания папок, структуры файлов и заполнения их содержимым по строкам. Каждая новая строка файла задается в отдельном блоке { ... }.

Пример использования:

p::apka:
[folder]
--{davai}
---[config.json, notes.txt]
----[my_data]
-=[config.json]
{"version": "1.0"}
{"mode": "debug"}
-=[notes.txt]
{Первая строка заметок}
{Вторая строка заметок}
vce

import::use

Команда подключения встроенных библиотек (math, mathp, jam) или модулей Python.

Пример использования:

import::use math
import::use jam

vce::ne

Команда мягкой паузы (ожидание нажатия клавиши Enter).

vce::ne

vce::nakonec

Полное завершение работы программы.

vce::nakonec

eto::xz

Специальная мусорная команда-заглушка для отладки или запутывания кода.

eto::xz
